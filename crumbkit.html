Built for Trust

Open source, local-first, and transparent by design

CrumbKit was built to fill the gap for a modern, Manifest V3 cookie editor that respects your privacy. Every line of code is open source (MIT). Frequently Asked Questions

No catch. CrumbKit is genuinely free — no Pro tier, no ads, no data collection. It's part of the WayKnow product family alongside ClearJSON and SnapMark. CrumbKit is our free acquisition tool — we earn revenue from our other products, not by charging for cookie management.

CrumbKit automatically classifies every cookie on the current site using name patterns and a bundled Disconnect.me tracking domain list. It calculates a 0–100 score: higher means fewer trackers. The score is color-coded — green (good), yellow (caution), red (many trackers). All classification happens locally — zero network requests.

Export (6 formats): JSON (.json), Netscape HTTP Cookie File (.txt — compatible with curl and wget), cURL command (.sh), CSV (.csv), Puppeteer script (.js), and Set-Cookie HTTP headers (.txt). Import: JSON and Netscape formats. The parser handles real-world cookie files reliably — including edge cases like special characters, missing fields, and large datasets.

CrumbKit can automatically delete cookies on a schedule. Create rules in the options page — e.g. "delete all advertising cookies every hour" or "delete cookies older than 30 days every Sunday". Rules run in the background via Chrome alarms, with optional notifications. Everything stays local — rules never leave your device.

Toggle the 📡 Intercept button in the popup and CrumbKit watches Set-Cookie response headers as you browse (up to 50 recent ones). Perfect for backend developers inspecting what servers set — add any intercepted cookie to the browser with one click, or copy it to inspect the attributes.

Yes. CrumbKit displays a blue "P" badge on partitioned cookies, keeps their top-level site info in the edit view, and preserves partition data across all 6 export formats and JSON import. As Chrome phases out third-party cookies, CHIPS partitioned cookies are preserved correctly.

Cookie Profiles let you save your current cookies as a named set and restore them later with one click. Perfect for developers who switch between testing environments — save your dev session, switch to staging, and restore dev whenever you need. Click the ⚙ Profiles button in the toolbar, give your current cookies a name, and you're done. Profiles are stored locally in your browser — never uploaded anywhere.

Yes! CrumbKit v1.1.0+ supports Chrome's Side Panel. Open it from the toolbar menu or right-click the CrumbKit icon — it opens in a wider panel that's perfect for browsing cookies while keeping the page visible.

Yes. All processing is local. There are zero network requests — open Chrome DevTools and verify. The tracking domain list is bundled with the extension, so classification works offline too.
