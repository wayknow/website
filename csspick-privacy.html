CSSPick Privacy Policy

Last updated: August 11, 2026

CSSPick is a Chrome extension for inspecting and copying CSS from web pages. This policy explains what data CSSPick handles and how.

Data Collection

CSSPick does not collect, transmit, or store any of your browsing data, page content, or CSS on any remote server. All inspection happens entirely inside your browser, on your device. The CSS you view is read from the page with Chrome's standard getComputedStyle API and displayed in the panel — it never leaves your machine.

What CSSPick Accesses

  • Active page structure and styles: When you click the CSSPick toolbar icon, the extension reads element geometry and computed CSS of the current page so it can highlight elements and show styles. This data is only shown to you in the panel and is never transmitted.
  • License key: If you enter a Pro license key, it is stored locally in chrome.storage.local on your device.
  • Device identifier: CSSPick generates a random, non-personal device ID (a UUID) used only to count how many devices a license key has been activated on (max 3 per key). It contains no identifying information about you or your hardware.

Remote Interactions

CSSPick makes exactly two remote connections, and only when you take a related action:

  • License verification: When you activate a Pro license key, it is sent to our license server (api.wayknow.tech) together with the random device ID and your browser's operating system and version. The server responds whether the key is valid. This happens only when you explicitly activate or launch the extension.
  • Purchase: Purchases are processed on creem.io, our payment provider. CSSPick never sees or stores your payment information.

Permissions

CSSPick requests the following Chrome permissions, and uses them only as described:

  • activeTab: To inspect the current tab only after you click the extension icon.
  • scripting: To inject the inspection script and styles into the current tab when you activate the extension. Scripts are removed when you exit inspect mode.
  • storage: To save your license key and license verification cache locally on your device.

CSSPick requests no host permissions and runs no background data collection.

Third-Party Services

CSSPick does not integrate with any analytics, tracking, or advertising services. Data is shared with no third party other than the license verification request described above.

Your Control

You can clear all CSSPick data at any time by removing the extension from Chrome, or by clearing the extension's storage in Chrome's extension settings.

Changes to This Policy
