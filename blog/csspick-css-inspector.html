CSS Inspection Shouldn't Cost $95 — Meet CSSPick

Published August 11, 2026 · 5 min read

The $95 inspector nobody's happy about

There's exactly one well-known paid tool for inspecting CSS in the browser: CSS Scan. It's been around since 2018, claims 20K+ developer users, and still sells for $95 as a one-time purchase — or $10–30/month for the "Pro" tier, with a $900 "lifetime" option on top.

And it has a 3.5-star rating. The reviews aren't complaining about bugs — they're complaining about the price. A browser extension that reads computed styles with a standard API, sold for $95, with a subscription tier that costs more than most dev tools.

Let's be honest about what an inspector does: it hovers an element, reads getComputedStyle, and displays the result. That's it. There is no server, no infrastructure, no recurring cost. The $95 price tag is the category's best example of pricing detached from cost.

Meanwhile the free alternatives are abandonware — the biggest has 345 users. CSSViewer hasn't been updated in years. CSS Peeper is aimed at a different workflow. Nobody is serving the simple need: "what styles does this element have, and how do I copy them?"

DevTools works. DevTools is also slow.

The honest answer everyone gives: "just use DevTools." And it's true — you can. Open the inspector, find the element in the DOM tree, click through to the Computed tab, mentally filter 200 computed properties down to the 10 you actually care about, then manually retype the ones you want.

That's a 30-second interaction for a question you ask dozens of times a day. Multiply that across a week of building interfaces and you've lost real hours.

Here's what the daily workflow actually looks like:

  1. Hover the element — see tag#id.class and its dimensions in a tooltip
  2. Click it — computed CSS appears, grouped into the 7 categories that matter: Color, Typography, Spacing, Size & Box, Background, Border & Shadow, Layout
  3. Click any property — it's copied as prop: value;

Three seconds, and you never opened the DevTools panel. That's the entire interaction model of CSSPick.

What CSSPick does

Click the toolbar icon and you're in inspect mode. No popup, no menu, no settings to configure. Hover highlights elements with a 2px indigo outline; the tooltip shows the selector and size. Click to lock an element, and the side panel shows its computed CSS in clean groups.

  • 7 property groups — Color, Typography, Spacing, Size & Box, Background, Border & Shadow, Layout. Only meaningful properties shown; empty values and 0px noise filtered out
  • Single-property copy — click any property, get prop: value; on your clipboard. Free, unlimited
  • Copy All CSS — the element's full computed CSS in one click (Pro)
  • Copy Selector — a clean tag#id.class path, up to 4 levels, for your own stylesheet (Pro)
  • Esc to exit — close the panel, leave inspect mode, back to normal browsing

We deliberately did not build the things CSS Scan Pro sells: no visual editor, no DevTools integration, no asset downloader. The position is simple. If you need to restructure a site's CSS, use DevTools. If you need to know what an element's styles are and copy them, CSSPick is faster than everything else in existence.

Free vs Pro — the $19 question

CSSPick Free is a complete inspector: hover, all 7 groups, single-property copy, no time limits, no watermark, no nagging. The only Pro features are the two copy conveniences — Copy All CSS and Copy Selector — which unlock at $19 once.

That's 80% less than CSS Scan's $95, with none of its subscription tier, and a rating problem it doesn't have to carry. The comparison is not subtle:

Three permissions. Zero host permissions.

This is the part we care most about. CSSPick requests activeTab, storage, and scripting — and nothing else. No host permissions, meaning the extension has no standing access to any website. It can't read anything until you click the toolbar icon, and the inspection script is removed when you exit inspect mode.

The CSS you inspect is read live from the page with Chrome's standard getComputedStyle API and shown only to you. Nothing is uploaded, stored, or transmitted — which is verifiable: open DevTools and check the Network tab while using it.

The one exception is Pro license verification, and it's exactly the same pattern as every other WayKnow product: your key is checked against api.wayknow.tech with a 7-day local cache, and that's the entire network footprint.

Why $19? Because that's what an inspector is worth — and because our business model is selling tools, not subscriptions. WayKnow products pay for themselves with a single lifetime purchase; CrumbKit and the free tiers are how people discover the ecosystem.

What we learned from SnapMark

CSSPick reuses the element-overlay technique from SnapMark's element picker — the hover-highlight system that took weeks to get right the first time. The license server follows the same proven pattern as ClearJSON: Cloudflare Worker + D1, Creem webhook, automatic key delivery by email.

That's the advantage of a product family: infrastructure that works, reused. Not infrastructure reinvented.
