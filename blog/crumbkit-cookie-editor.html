CrumbKit — Why We Rebuilt Our Cookie Editor from Scratch

Published July 27, 2026 · 5 min read

What happened to EditThisCookie?

For over a decade, EditThisCookie was the go-to cookie manager for Chrome. 3 million users. 11,000+ reviews. It did one thing and did it well: let you view, edit, import, and export cookies for any site.

Then Chrome's Manifest V2 deprecation hit. Over 50,000 extensions were removed or disabled. EditThisCookie was one of them.

Within weeks, a fake clone appeared on the Chrome Web Store — using a similar name and icon. It scammed 50,000 people before being taken down. The original author never migrated to Manifest V3. The 3 million users were left with nothing.

This pattern isn't unique to cookie editors. Popular extension gets removed → shady clones rush in → users get their data harvested. We've seen it with JSON Formatter (sold, injected ads), screenshot tools (forced cloud upload), and dozens of others.

What are people using now?

After EditThisCookie disappeared, a few alternatives stepped up:

AlternativePricingThe catch
Cookie-EditorFree, open sourceBare-bones — no import/export, no search, no classification
CookieJar$4.99/monthSubscription for a tool that reads local browser data
EditThisCookie (clone)FreeWho knows what it does with your data? Not open source

None of them hit all three: free, open source, and actually useful.

Why we built CrumbKit

We originally built a cookie editor called CookieClear. It passed all our tests, looked great, and was ready to ship. Then the Chrome Web Store hard-blocked it for keyword spam — we had used competitor names in the store listing. One appeal, one chance. We cleaned everything, submitted the appeal, and won. The block was lifted.

But here's the thing: even with the block lifted, the item ID had a spam violation on its record. In the Chrome Web Store, that affects your search ranking. Permanently.

So we did something painful but obvious: we killed CookieClear and rebuilt it as CrumbKit. Same code, same features, same commitment to privacy. But a clean item ID, a clean record, and a name that says what it is — "cookie crumbs" + "toolkit."

Lesson learned: never put competitor names in your Chrome Web Store listing. Not in the title, not in the description, not in the promo images. The first rejection was our fault. CrumbKit's store listing mentions no competitor by name.

What CrumbKit does

Everything you'd expect from a cookie editor, plus a few things you wouldn't:

  • View, create, edit, delete — full CRUD for every cookie on the current site
  • Privacy Score — 0–100 score with color-coded gauge, powered by a bundled Disconnect.me tracker database (100% offline)
  • Cookie classification — auto-labels every cookie: Essential, Functional, Analytics, Advertising, or Social
  • Batch operations — select multiple cookies to delete them at once, or bulk-edit domain, path, Secure, HttpOnly, and SameSite across the selection. Whitelist protects your important cookies
  • Import & export — 6 formats — JSON, Netscape (curl/wget), cURL command, CSV, Puppeteer script, and Set-Cookie headers. Parser handles real-world edge cases
  • Cookie profiles — save and restore cookie sets as named profiles. Switch between dev, staging, and production sessions in one click
  • Scheduled auto-cleanup — rules that purge cookies by domain, category, or age — hourly, daily, or weekly
  • Set-Cookie interceptor — watch Set-Cookie response headers in real time and add intercepted cookies with one click
  • CHIPS partitioned cookies — full support, with partition data preserved across all 6 export formats
  • Undo support — up to 50 actions, Ctrl+Z to reverse
  • Real-time search — type to filter in a compact table view, find what you need in a list of hundreds
  • Side panel support — open CrumbKit in Chrome's Side Panel for a wider view
  • Dark & light mode — follows system preference, toggle anytime

Completely free. No, really.

CrumbKit has no Pro tier, no ads, no data collection, no sign-up. It's MIT open source — every line of code is public and auditable.

Why free? Because CrumbKit is our acquisition tool. We make money from SnapMark ($39 lifetime screenshot tool) and ClearJSON (free core, Pro from $2.99/month). CrumbKit is how people discover the WayKnow ecosystem. It costs us almost nothing to maintain — the chrome.cookies API hasn't changed in 10 years, and the entire extension is pure vanilla JavaScript with zero dependencies.

The tracker database (from Disconnect.me) is bundled with the extension, so classification works offline. Open Chrome DevTools on any page with CrumbKit installed and check the Network tab — you'll see zero requests from the extension.

What to look for in a cookie editor

If you're comparing options, here's what matters:

  1. Is it open source? A cookie editor can see every cookie on every site you visit. You should be able to verify what the code does.
  2. Does it make network requests? There's no reason a cookie editor needs to talk to a server. If it does, ask why.
  3. Is it Manifest V3? MV2 extensions are being phased out. If it's still MV2, it will stop working.
  4. Does it have a business model you can see? If an extension is free with no visible revenue, you're probably the product.
