ColorPeek Is Here — A macOS Color Picker Built for Developers

Published July 27, 2026 · 5 min read

The macOS color picker is 20 years old

Open the built-in macOS color picker — the one that pops up when you press Shift+Cmd+C in most apps. It shows you a color wheel. Click around, and you get… a hex code. That's it.

No history of previously picked colors. No format switching. No Tailwind class names, no CSS variables, no SwiftUI Color initializers. Just a hex code.

This tool hasn't changed meaningfully since Mac OS X Tiger. Meanwhile, the people picking colors from their screens — developers — now work with a dozen different color formats. Tailwind. SCSS. CSS custom properties. SwiftUI Color. OKLCH. The built-in picker supports exactly one of these.

What's already out there

There are paid alternatives. But they're all built for designers:

AppPriceThe problem
Sip Pro$59 one-time (pushing subscription)Feature bloat — team collaboration, cloud sync, commenting. Designers want palettes; developers want a color code.
ColorSlurp$29 one-timeBeautiful UI, but designer-centric. No developer formats like Tailwind or SwiftUI Color.
PikaFree, MIT open sourceExtremely minimal — 10 history entries, few formats. Great for quick picks, not enough for daily use.

Someone is making money in this category — Sip Pro and ColorSlurp prove that. But nobody is making a color picker for developers. Everyone is chasing the Figma/Sketch designer workflow. We saw the gap and went the other way.

What ColorPeek does differently

ColorPeek is a menu bar app. Click the eyedropper icon, pick a color anywhere on your screen. That's the entire interaction model. No windows to manage, no dock icon, no project files.

8 color formats, switch with one click:

  • HEX — #3B82F6
  • RGB — rgb(59, 130, 246)
  • HSL — hsl(217, 91%, 60%)
  • OKLCH — oklch(0.62 0.22 264) (full sRGB → Linear RGB → XYZ → LMS → OKLab pipeline)
  • Tailwind — blue-500 or [#3B82F6] (matches against 242 Tailwind 3.4 colors via Euclidean distance)
  • SCSS — $color: #3B82F6;
  • CSS var — --color: #3B82F6;
  • SwiftUI Color — Color(red: 0.231, green: 0.510, blue: 0.965)

Other things it does:

  • Unlimited history — every color you've ever picked, searchable by hex code
  • Custom palettes — save and organize colors into named collections
  • Quick-access strip — last 6 colors always visible in the menu bar popup
  • Pick from images — paste a screenshot or design mockup, click to extract colors
  • Global hotkey — Cmd+Shift+C to activate the picker from anywhere

Why SwiftUI and not Electron

We built all our other products as Chrome extensions. ColorPeek is our first native macOS app. We chose SwiftUI over Electron for three reasons:

  1. Menu bar apps should be invisible. Electron apps sit in the Dock by default and consume 100MB+ of RAM before doing anything. A color picker needs to be lightweight — ColorPeek uses ~25MB.
  2. NSColorSampler already exists. Apple's color sampler API is excellent — system-level magnifying glass, works across all displays and spaces. Rebuilding this in a web view would be worse at every level.
  3. Launch at login, no splash screen. A color picker you have to manually open is a color picker you won't use. ColorPeek starts with your Mac and sits in the menu bar, invisible until you need it. SMAppService handles this natively; Electron requires workarounds.

The trade-off: SwiftUI means macOS-only, no Windows or Linux. That's fine. The people who care about color-picking tools on macOS are a specific, underserved audience. We'd rather serve them well than serve everyone poorly.

Free vs Pro

The free tier gives you 4 formats (HEX, RGB, HSL, OKLCH), 50 history entries, and the magnifying glass picker. Pro ($19, one-time) unlocks 4 more formats (Tailwind, SCSS, CSS var, SwiftUI Color), unlimited history, custom palettes, and image color picking.

$19 once, no subscription, no account required. The license key is verified locally with a 7-day offline cache — if our server is down, ColorPeek keeps working.

There's no forced upgrade path. If you only need hex codes, ColorPeek is a free, permanent upgrade over the built-in picker. Pro is for developers who work across multiple color formats daily.

Is this a real market?

The color picker market is tiny compared to screenshot tools or JSON viewers. We project $5K–10K in the first year — not a flagship revenue product. But that's not the point.

ColorPeek is our desktop experiment. It validates that we can build, sign, notarize, and sell a native macOS app — the same pipeline we'll use for larger desktop products later. It's also a brand entry point: someone who discovers WayKnow through ColorPeek might also need a JSON viewer or screenshot tool.

And honestly? We use it every day. Sometimes you build something because you need it yourself, and if other people pay for it too, that's a bonus.
